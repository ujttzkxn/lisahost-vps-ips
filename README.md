**双 ISP 家宽住宅 IP 是什么。** 简单说，IP 同时挂在两家 ISP 名下，并且属于家宽住宅段（不是机房段）。这种 IP 在 TikTok、Netflix、迪士尼+等流媒体和社媒平台的判断系统里更接近"真实家庭用户"，解锁成功率和账号数据表现通常会比普通机房 IP 更稳。代价是价格更高、流量更紧。

不是。双ISP 家宽住宅 IP 仍然是 ISP 段（虽然是住宅段），家宽VDS（如加州 Astound、西雅图 Atlas）则是真实接在美国家庭宽带运营商名下的 IP，更接近"真实民房住宅"。后者价格更高、流量更紧，但在亚马逊等对 IP 属性最敏感的场景里更稳。

**Q：流量不够用怎么办？**

可以走不限流量的方案（gid=30 分组），但价格更高。年付特价系列里，新加坡 300Mbps/2000GB、台湾 100Mbps/2000GB 流量配额最大；美国方向多数套餐在 600GB/月，跑小站、代理够用，跑大文件下载或视频搬运会很快超。

**Q：能不能装 Windows？**

KVM 架构支持自行安装 Windows 系统，但 LisaHost 不提供 Windows 镜像授权，需要自备 ISO 和授权。Linux 系列镜像一键安装免费。
